# Field Workflow

1. Authenticate as a valid hospital user.
2. Select the tenant context.
3. Book an appointment for a doctor and patient.
4. Attempt a duplicate booking on the same slot.
5. Observe the conflict response and audit log.
6. Inspect storage metrics and retention thresholds.
7. Trigger an experiment or forecast run.
8. Review forecast results, confidence, and risk.
9. Adjust configuration as an administrator when the policy needs to change.

This flow reflects the structured prototype review and the operational needs of a field-ready hospital scheduling system.
